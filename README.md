# A-Comparative-Study-of-High-Cardinality-Encoding-Techniques-for-Machine-Learning
A comparative study of eight high-cardinality categorical encoding techniques using a ride-hailing complaints dataset. This project evaluates Capped One-Hot, Frequency, Target, Smoothed Target, Leave-One-Out, WoE, XGBoost Native, and LightGBM Native using Accuracy and ROC-AUC.
